# SeoKitHub — Free SEO Toolkit

> 10 free SEO & developer tools. No AI costs, no account, no limits.

**SeoKitHub** is a fully SEO-optimized web application built with **Laravel + React + Inertia.js**. Every tool runs in the browser or via a lightweight server-side analysis — zero AI API costs.

**Live domain:** [seokithub.com](https://seokithub.com)

## Local Development

### Requirements

- PHP 8.2+
- Composer
- Node.js 20+ & npm
- Laravel CLI

### Setup

```bash
# 1. Clone the repo
git clone https://github.com/your-username/seokithub.git
cd seokithub

# 2. Install PHP dependencies
composer install

# 3. Install JS dependencies
npm install

# 4. Set up environment
cp .env.example .env
php artisan key:generate

# 5. Start the servers (two terminals)
php artisan serve        # Laravel on http://localhost:8000
npm run dev              # Vite HMR on http://localhost:5173
```

Open `http://localhost:8000` in your browser.

## SEO Features

- **Unique title + meta description + keywords** on every page
- **JSON-LD structured data** auto-injected on every tool page:
  - `WebPage`, `SoftwareApplication`, `FAQPage`, `BreadcrumbList`
- **SEO-friendly URLs** — `/seo-audit-tool`, `/xml-sitemap-generator`, etc.
- **Dynamic `/sitemap.xml`** — all 10 tool URLs with priority & changefreq
- **`/robots.txt`** — `Allow: /` with sitemap reference
- **How-to sections** and **FAQ sections** on every tool page (targets Google's People Also Ask)
- **Internal linking** via Related Tools on every page

## Deployment

See [`DEPLOY.md`](./DEPLOY.md) for full deployment instructions covering Railway, cPanel, and DigitalOcean.

**Quick deploy checklist:**

```bash
# Build frontend assets
npm run build

# Laravel optimizations
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

After deploy, submit your sitemap:
- [Google Search Console](https://search.google.com/search-console/) → Sitemaps → `https://seokithub.com/sitemap.xml`
- [Bing Webmaster Tools](https://www.bing.com/webmaster/) → Sitemaps
